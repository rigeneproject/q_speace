## Task and preregistered interpretation

An actual LLM subagent diagnoses a fixed synthetic sensor record before tools,
then reviews the results of the online MCP client. Sensor A temperatures are
[22,85,21,86], independent reference B [22,22,21,22], vibration RMS
[0.12,0.11,0.12,0.12]; high A readings have checksum failures. Ordered classes:
normal, bearing_fault, sensor_fault. Synthetic reference label: sensor_fault.
The LLM must explain the evidence and recommend inspection only.

The client is a deterministic policy adapter, not an LLM model. The subagent
provides the language/reasoning component; no new model API key is required.
Fixture distributions [[.05,.05,.9],[.1,.1,.8]] are fixed synthetic inputs,
not probabilities generated by the LLM or calibrated diagnostic outputs.
Baseline and final LLM decisions are recorded separately from client output.
One fixture cannot establish a causal performance or efficiency improvement.

## Mechanisms and limits

1. OAuth client credentials from the existing ignored, ACL-restricted operator
   file; fixed HTTPS issuer/audience. Token remains in memory, never logged.
2. Initialize, ping and scope-filtered discovery via official SDK 1.30.0.
3. Query BCEL Homeostasis and require a functional classification.
4. Define phi = 1 - TV(p1,p2), TV = sum(abs(p1-p2))/2. This is an explicit
   agreement proxy, not calibrated confidence or entropy in nats.
5. Obtain adaptive_clock_rate; apply bounded actual sleep min(.1,1/r).
6. Obtain a metabolism estimate for a synthetic operation (zero qubits, one
   gate, duration .01 s, utility 2, entropy change 1). Require finite nonnegative
   estimated energy and passes_sevo; independently reserve estimate before
   aggregation. Default modeled-energy ceiling .001 J. It does not bound the
   physical energy of the LLM, network or server; no DAT mutation is exposed.
7. Aggregate the fixed distributions. Validate normalized output, pick argmax,
   and report a read-only inspection advisory. LLM interpretation remains separate.
8. Probe invalid clock input; require isError=True followed by a successful ping.
9. Demonstrate refusal of the sixth tool call under a five-tool-call hard cap.

Tool-call budget is reserved before dispatch, including errors; failed attempts
are charged. Transport handshake/ping/list/DELETE are counted separately and
are not part of this five-tool cap. No automatic retries. RPC timeout 60 s,
whole experiment 180 s; tool errors fail closed except the explicit error probe.
Per-request and total duration are logged. Output goes to a new directory only;
partial events survive failure, and a failure summary is saved.

## Evidence and acceptance

JSONL events record only synthetic inputs/results, tool latency, decisions and
policy reservations; summary includes endpoint, versions, script hash, task hash,
tool cap, modeled-energy reservation, both class distributions and final class.
No headers, client IDs, secrets, JWTs or raw exceptions are logged. Verify
connectivity, four successful tool computations, invalid-input recovery and
local pre-dispatch budget refusal. Assess reference-label agreement separately
from baseline/final LLM reasoning; publish failures and unchanged outcomes.

Tests use a fake MCP session for budget exhaustion, errors, malformed numerical
results, energy refusal and success. The live run is explicit, not a CI default.
Run pytest, py_compile, Ruff, Black and mypy on touched code. BCEL classification
records feedback as functional mathematics, not biological cognition or safety
certification. No physical or economic actions, self-modification, new client
grants or remote writes are permitted by this experiment.


## Observed run — 2026-11-21

One explicit public execution passed in 41.062 s. SDK 1.30.0 negotiated the
service and discovered eight tools. Four computations succeeded; the fifth
call intentionally used invalid clock input and returned isError=True. A
subsequent ping passed. A sixth tool call was refused locally before dispatch.
Coherence proxy .9 produced rate 31.6227766 and an applied .0316228 s sleep.
Modeled energy reservation .0003094 J was below the .001 J ceiling; Sevo 2
passed. These are synthetic operation estimates, not measured service energy.

The fixture barycentre was [.0714286,.0714286,.8571429], selecting sensor_fault.
The actual LLM subagent independently selected sensor_fault before tools and
retained it after inspecting the MCP results. Inspection only was recommended.
There is no measured diagnostic improvement, no calibrated confidence and no
provider-token or real-energy measurement. Cloud/tool overhead dominates the
small numerical task; five worker calls took roughly 7–8 seconds each.
